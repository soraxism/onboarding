## Part 2. 個人記入【参加者全員 / 3分 → Slackスレッドへ一斉投稿】

**手順**
1. まずSlackの**下書き欄**に3分で書く。**送信しない**
2. ファシリテーターの合図で**一斉に**スレッドへ投稿する
3. 他の人の投稿は、自分が送信してから読む

> 先に投稿された内容を読むと引きずられます。下書き → 一斉投稿で独立性を保ちます。

### 投稿テンプレート（コピーして使う）

```
A. 決められなかったこと
1.
2.
3.

B. 誰に聞けば分かるか、分からなかったこと
1.
2.
3.

C. 存在しなかったもの
1.
2.
3.

D. 自由記述（任意）

```

### 各項目の意味

| 項目 | 書くこと |
|---|---|
| **A. 決められなかったこと** | 判断が止まった、誰が決めるのか分からなかった、決めたけど自信がない |
| **B. 相談先が不明だったこと** | 「これ、誰に聞けばいいんだ」と思った瞬間。法務、契約書の在り処、過去事例など |
| **C. 存在しなかったもの** | あるはずだと思ったのに、なかったもの。窓口・連絡先リスト・テンプレート・規程・権限・ツールなど |
| **D. 自由記述** | 訓練中に感じた違和感、実際に起きたらもっと困りそうなこと |

## Part 4. 確認漏れチェック【ファシリテーター】

集約結果に以下が含まれているか確認します。**含まれていなければ、その場で問いかけてください。**

### 体制・判断

- [ ] 一次受け（営業/CS）から責任者へのエスカレーション先は決まっているか
- [ ] 「疑い」の段階で上げてよいという合意はあるか
- [ ] 「知った時」を記録する運用はあるか
- [ ] 証跡保全の手順はあるか
- [ ] 委託／自社取得の契約上の整理を、誰が答えられるか
- [ ] 法務・顧問弁護士への相談ルートと連絡先はあるか
- [ ] 公表判断の権限者は決まっているか
- [ ] 報道対応の窓口は決まっているか

### リモート / Slack運用

- [ ] **インシデント発生時にどこに集まるか決まっているか**（専用チャンネルの命名規則・ハドル運用）
- [ ] **DMで判断を閉じないルールはあるか**
- [ ] **顧客との共有チャンネルと社内チャンネルの使い分けルールはあるか**
- [ ] **音声で決めたことをSlackに書き戻すルールはあるか**
- [ ] **Slackが見られない時間帯・状況の代替連絡手段はあるか**（電話番号リストの有無）
- [ ] 夜間・休日の連絡経路はあるか
- [ ] Slack上の証跡（メッセージ・共有ファイル）を消さない・保全する手順はあるか

### 対外対応・技術

- [ ] 顧客への通知文テンプレートはあるか
- [ ] 削除依頼・削除証明の書式はあるか
- [ ] **Athenaからの手動抽出に、テナント絞り込みのレビュー工程はあるか**
