## 状態の定義

| 状態 | 意味 |
|---|---|
| 未着手 | 担当が決まっていない、または着手していない |
| 対応中 | 着手済み。ドラフトがある |
| レビュー中 | ドラフトを関係者レビューに出している |
| 完了 | 確定し、参照できる場所に置かれ、関係者へ周知済み |
| 見送り | 対応しないと決めた（**理由を必ず書く**） |

**「ドキュメントを書いた」は完了ではない。** 置き場所が決まり、関係者が見つけられる状態で完了。
