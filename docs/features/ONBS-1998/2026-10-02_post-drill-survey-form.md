# 訓練後アンケート（Googleフォーム）テンプレート

参加者の個人記入（A / B / C）を Google フォームで集めるためのテンプレート。
**回答と集約はスプレッドシートで管理する**（振り返りシートの xlsx には転記しない）。
集約結果は、振り返りシートの **Part 2「確認漏れチェック」** と
`2026-10-02_action-plan.md` の材料になる。

> **設計の前提**: 集めたいのは**感想でも評価でもなく、困ったこと**。
> 設問は A / B / C の3つが本体で、ほかは最小限にする。設問を増やすほど本体の記述が薄くなる。

---

## フォームの設定

| 項目 | 値 |
|---|---|
| タイトル | 個人情報漏えい 机上訓練 振り返り（2026-10-02） |
| 回答期限 | **当日中**（記憶が薄れる前に。翌日以降は内容が一般論になる） |
| ログイン要求 | 社内限定 ON |
| メールアドレスの収集 | **しない**（記名は任意の設問で受ける） |
| 回答の編集 | 許可する（あとから思い出すことがあるため） |
| 進捗バー | OFF（短いため） |
| 回答のコピーを送信 | 許可する |

### 説明文（フォーム冒頭にそのまま貼る）

```
お疲れさまでした。5分ほどで終わります。

この訓練のゴールは「うまく対応できたか」ではなく、
「決められなかったこと」を見つけることでした。
ここで集めた内容が、そのまま対応フローの目次になります。

3つだけお願いします。

・うまくできたことは書かなくて大丈夫です
・「こうすればよかった」も書かなくて大丈夫です
・困ったこと、詰まったこと、分からなかったことだけを書いてください

誰かの対応を評価するためには使いません。無罰ルールのままです。
本日中にご回答ください。
```

## 設問一覧

### Q1. お名前（任意）

| | |
|---|---|
| 種類 | 記述式（短文） |
| 必須 | **いいえ** |
| 説明 | 書かなくて構いません。後で詳しく聞きたいことがあったときに使います。 |

> **記名を任意にする理由**: 書きにくいことを書いてもらうため。
> ただし全員が無記名だと「誰が何に詰まったか」を追えないので、
> **Q2（役割）は必須**にして、立場ごとの傾向だけは取れるようにする。

### Q2. 今日の役割

| | |
|---|---|
| 種類 | ラジオボタン |
| 必須 | **はい** |
| 選択肢 | 一次受け（CS） ／ 統括判断 ／ 調査（エンジニア） ／ オブザーバー ／ その他 |

### Q3. A. 決められなかったこと

| | |
|---|---|

## 追加してもよい設問（任意・最大2問まで）

本体（A/B/C）の記述量が落ちるため、**入れるなら2問まで**にする。

### Q7. 同じことが実際に起きたら、今日と同じように動けると思いますか

| | |
|---|---|
| 種類 | ラジオボタン |
| 選択肢 | 動けると思う ／ たぶん動ける ／ 自信がない ／ 動けないと思う |
| 狙い | フロー整備の優先度を測る。「自信がない」以下が多ければ、フローは**手順書まで落とす**必要がある |

### Q8. 今日いちばん時間を取られたのはどこですか

| | |
|---|---|
| 種類 | ラジオボタン（＋その他） |
| 選択肢 | 誰に連絡するかの判断 ／ 原因の確認 ／ 影響範囲の確定 ／ 報告義務の判断 ／ 顧客への返信文の検討 ／ 情報がどこにあるか探すこと |
| 狙い | フローのどの章を厚く書くかの判断材料 |

## Apps Script で生成する

手で作ってもよいが、設問が7つあるため**スクリプトのほうが速く、取り違えもない**。

1. [script.google.com](https://script.google.com) で新規プロジェクトを作成
2. 下記を貼り付けて実行（初回は権限の承認が必要）
3. ログに出力された URL を開く

```javascript
function createDrillSurvey() {
  const form = FormApp.create('個人情報漏えい 机上訓練 振り返り（2026-10-02）')
  form.setDescription(
    'お疲れさまでした。5分ほどで終わります。\n\n' +
    'この訓練のゴールは「うまく対応できたか」ではなく、\n' +
    '「決められなかったこと」を見つけることでした。\n' +
    'ここで集めた内容が、そのまま対応フローの目次になります。\n\n' +
    '3つだけお願いします。\n\n' +
    '・うまくできたことは書かなくて大丈夫です\n' +
    '・「こうすればよかった」も書かなくて大丈夫です\n' +
    '・困ったこと、詰まったこと、分からなかったことだけを書いてください\n\n' +
    '誰かの対応を評価するためには使いません。無罰ルールのままです。\n' +
    '本日中にご回答ください。'
  )
  form.setCollectEmail(false)
  form.setAllowResponseEdits(true)
  form.setProgressBar(false)

  form.addTextItem()
    .setTitle('お名前（任意）')
    .setHelpText('書かなくて構いません。後で詳しく聞きたいことがあったときに使います。')
    .setRequired(false)

  form.addMultipleChoiceItem()
    .setTitle('今日の役割')
    .setChoiceValues(['一次受け（CS）', '統括判断', '調査（エンジニア）', 'オブザーバー', 'その他'])
    .setRequired(true)

  form.addParagraphTextItem()
    .setTitle('A. 決められなかったこと')
    .setHelpText('判断が止まった、誰が決めるのか分からなかった、決めたけれど自信がない。\n' +
                 '箇条書きで、思いつく限り書いてください。1行でも構いません。')
    .setRequired(true)

  form.addParagraphTextItem()
    .setTitle('B. 誰に聞けば分かるか、分からなかったこと')
    .setHelpText('「これ、誰に聞けばいいんだ」と思った瞬間。\n' +
                 '法務、契約書の在り処、過去の事例、権限を持っている人など。')
    .setRequired(true)

  form.addParagraphTextItem()
    .setTitle('C. 存在しなかったもの')
    .setHelpText('あるはずだと思ったのに、なかったもの。\n' +
                 '窓口・連絡先リスト・テンプレート・規程・権限・ツールなど。')
    .setRequired(true)

  form.addParagraphTextItem()
    .setTitle('D. 自由記述（任意）')
    .setHelpText('訓練中に感じた違和感、実際に起きたらもっと困りそうなこと。')
    .setRequired(false)

  // 任意設問（不要ならこのブロックを消す）
  form.addMultipleChoiceItem()
    .setTitle('同じことが実際に起きたら、今日と同じように動けると思いますか')
    .setChoiceValues(['動けると思う', 'たぶん動ける', '自信がない', '動けないと思う'])
    .setRequired(false)

  Logger.log('回答用: ' + form.getPublishedUrl())
  Logger.log('編集用: ' + form.getEditUrl())
}
```

## 回答後の扱い

1. フォームの回答をスプレッドシートに出力する（フォーム編集画面の「回答」→ スプレッドシートにリンク）
2. A / B / C ごとに全員分を並べ、**同じ内容をまとめて件数を付ける**
   - **重複は消さない。** 複数人が挙げた項目 ＝ 優先度が高い項目
3. 集約はこのスプレッドシート上で完結させる（**xlsx には転記しない**）
4. 振り返りシート（xlsx）の **Part 2「確認漏れチェック」** で、抜けている論点がないか突き合わせる
5. `2026-10-02_action-plan.md` の「アンケートからの追加分」へ転記し、担当と期限を付ける

> **Slackスレッドで集める場合との違い**: フォームは他の人の回答が見えないため、
> **引きずられずに書ける**（独立性が高い）。一方で、その場で読み上げて深掘りすることはできない。
> 回答が出そろったら、集約結果をチャンネルへ戻して共有する。

### 回答が集まらないとき

- 期限当日の終業前に、チャンネルで一度だけリマインドする
- **未回答でも責めない。** 回答が少ないこと自体が「訓練の優先度が低く見えている」という情報
