# 個人情報漏えい 机上訓練

**管理画面のログインレポートCSVダウンロード機能の不具合**で、顧客が自分でダウンロードしたCSVに
他社プロダクトのデータが混入していた、という想定で行う60分の机上訓練一式。
**実システムには一切触らない。主催側からは会議を設定せず、すべてSlackで行う。**

**成果物は「うまく対応できたかの評価」ではなく「決められなかったことのリスト」。**
当社には対応フローも CSIRT 相当の組織も無いため、この訓練は
**フローに何を書くべきかを洗い出す要件定義**として実施する。参加者が詰まるほど成功。

> **取扱注意**: 進行台本と Slack投入用テキストは**ファシリテーターのみ**が持つ。
> 参加者に渡してよいのは、訓練終了後の**参加者配布資料だけ**。

## 守ること

- **実際のクライアントとのSlackチャンネル（Slack Connect含む）には絶対に投稿しない**
- 台本と投入テキストを参加者に渡さない。配布してよいのは終了後の配布資料だけ
- **訓練は必ずその日のうちに終了させ、ネタバラシまで行う**
- 参加者が本物のクライアントや社外に連絡しようとしたら、**即座に訓練であることを明かして止める**
- 訓練用チャンネルは**削除ではなくアーカイブ**する（訓練記録として残す）
